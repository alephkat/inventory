# Simple Inventory App

Easy inventory management for a small shop in Zambia.

## How to Run

### Backend

1. cd backend
2. npm install
3. npx prisma generate
4. npx prisma db push
5. node src/seed.js
6. npm start (runs on http://localhost:4000)

Login: admin / admin123

### Frontend (Flutter)

1. cd frontend
2. flutter pub get
3. flutter run
